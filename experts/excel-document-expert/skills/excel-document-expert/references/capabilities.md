# 能力与保真边界

默认目标是普通xlsx多sheet新建、读取、修改、清洗去重、合并汇总、样式、公式、原生图表；需要当前会话提供对应工具或已有库/计算引擎，执行前检测。CSV/TSV可作为输入，但必须明确编码、分隔符、类型和数值口径，不能冒充完整工作簿编辑。

| 内容 | 单独验证要求 |
|---|---|
| 公式缓存 | 实际引擎计算、保存、复读；写公式不算计算完成 |
| 新函数/动态数组 | 完整结果范围和依赖链，不能只查左上角 |
| 外部工作簿链接 | 关联文件与来源明确，保护公式/缓存/关系，不自动断链硬编码 |
| 透视表/缓存 | 创建、读取、保存保留、刷新分别验收；分组汇总不是可交互透视 |
| 切片器/模型/连接 | 普通库停止写回，原生路径也要验证对象可用 |
| 宏与签名 | 不执行宏；keep_vba=True不证明功能或签名保真 |
| 嵌入对象/控件/复杂图形 | 先识别支持情况，在副本验证，不能静默丢失 |
| xls/xlsb/加密文件 | 需已有原生工具安全读取/转换，否则说明阻断 |
| 超大表格 | 明确全量范围、资源限制与分块，不用样本冒充全量 |

合格成果应有清楚主表、原始依据、口径与单位，可重算的公式仍为公式，图表为真实可编辑对象。保留原件，说明变更，报告实际验证及未验证内容。本机成功不能推断所有付费云端可用。
