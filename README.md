## 财务对账与月结专家

<img src="assets/finance-icon.jpg" width="144" height="144" alt="财务对账与月结专家图标">

**把差异找出来，把月结安排清楚。** 提供同口径的两份 CSV，得到逐笔匹配依据、未清事项、账龄和待复核问题；提供月结任务与变动明细，还可检查关键路径、角色缺口、人员超载及需要解释的重要变化。

三个工具使用 Python 3 标准库，结果包含中文说明与 JSON。匹配是待核实的辅助结果；不连接银行，不自动记账、付款或核销，不承诺原生 Excel 工作簿处理。

## 供应商评估专家

<img src="assets/vendor-evaluation-expert-icon.png" width="144" height="144" alt="供应商评估专家图标">

**续约评审有依据，改进任务有方向。** 提供已有 IT、SaaS 供应商目录和服务指标，生成五维绩效评分、月度/季度指标差距、四维风险矩阵和待补证据清单。可以只做一项，也可以形成完整评审摘要。

报告、状态、建议和错误提示默认中文；“服务指标未达标”不会直接写成合同违约。非美元支出按你提供的汇率、日期与来源折算，不擅自查汇率。仅用本地材料和 Python 标准库，不接采购或监控系统。

## 数据质量专家

<img src="assets/data-quality-expert-icon.png" width="144" height="144" alt="数据质量专家图标">

**不只看质量分，还能定位到原值和行号。** 提供 CSV 与已确认的业务规则，检查缺失、重复、类型、范围、枚举和时效；对指定数值列选择四分位距、标准分数或修正标准分数方法，定位需要复核的记录。

默认交付中文报告，按需同时保留 JSON 明细；原编号、前导零与原文件保持不变。未知维度写明未检查，统计异常保留为待复核线索，不自动删行、填补或改数。当前输入为 UTF-8 / UTF-8-BOM CSV 和规则 JSON，不直接读原生 Excel 或连接数据库。

## 项目管理专家

<img src="assets/project-management-expert-icon.png" width="144" height="144" alt="项目管理专家图标">

**知道哪里卡住进度，也知道多花两天会影响什么。** 提供任务、人员、期限和依赖，计算排期、关键路径、浮时与人员冲突；保留原计划，比较增加工期后的日期与影响范围。资料齐全时，还可分析跨项目容量、五维健康与风险。

交付中文报告、JSON 明细和相应 CSV，配套项目章程、责任分工与管理层汇报模板。按周一至周五及提供的假期计算；发现冲突明确列出，不自动分配人员、不保证最优排期，不更新外部项目系统。
