# 办公专家 Skills

## 免费办公专家入口

免费专家先解决一个明确的小任务：账表初检、供应商资料准备、任务清单梳理或单表概览；完整自动对账、绩效评分、依赖排期和数据质量检查仍由原有收费技能提供。Excel、Word、PPT保持现有免费定位。2026-10-25，四款免费专家已完成同名1.0.1范围修订，已逐个提交审核，尚未上架；旧包已撤回，未新增Pro产品。

查看[专家入口与使用示例](EXPERTS.md)。收费技能的原内容、原价格与审核保持不变；免费修订包不再内置收费引擎。正式市场安装与调用以平台审核后的实际状态为准。

用户可见文案优先用“动词＋对象”说清任务，例如“检查账表格式”“整理供应商资料”“整理任务清单”“查看字段与空值”。主要提示、表头、状态和报告使用直白中文；必要的文件格式、原始字段名及平台英文标识保留。

把办公资料变成能检查、能继续修改的成果。面向 WorkBuddy，覆盖财务月结、供应商评审、数据质量、项目管理、Word/Excel 文档处理与 PPT 制作；每个产品独立使用，交付结果与输入依据对应。
