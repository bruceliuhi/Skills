# 办公专家 Skills

把办公资料变成可检查、可继续使用的成果。面向 WorkBuddy，每个产品覆盖一类完整任务，完成验收后单独发布。

## 财务对账与月结专家

<img src="assets/finance-icon.jpg" width="144" height="144" alt="财务对账与月结专家图标">

**两边账目哪里不同、差异需要补什么依据、月结卡在哪一步，一次看清。**

- **两份 CSV 对账**：核对总账与银行流水或业务明细，列出逐笔匹配依据、未清事项、账龄和待复核问题。
- **月结排期**：根据任务依赖、责任人和时长，计算关键路径，提示角色缺口及人员超载。
- **重要变动检查**：按照确认的金额和比例阈值，筛出需要解释、量化和补依据的变化。

三个计算工具只使用 Python 3 标准库，无需额外服务账号或 API。结果包含中文说明与 JSON；CSV/JSON 输入按技能说明准备。当前不承诺直接处理 Excel 工作簿，也不连接银行、自动记账、付款或核销。

代码位于 `skills/finance-reconciliation-expert/`。开始使用、输入格式与操作方法见该目录的 `SKILL.md`。对账匹配是待核实的辅助结果，凭证真实性和最终业务处理需由负责人确认。
