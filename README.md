# 办公专家 Skills

面向 WorkBuddy 的办公技能产品：让用户更快完成真实任务，拿到可编辑、可检查、可继续使用的成果。

## 交付原则

- 保留成熟实现的完整核心功能，完成目标平台适配后再发布。
- 每做好一个、验收一个、发布一个；不等待整个产品组合完成。
- 名称和介绍围绕用户会搜索的问题，展示真实成果，承诺与能力一致。
- 核心路径力求无需用户另开服务账号、购买 API 或手动安装环境。
- 不覆盖原资料；失败明确可见；支持局部修改和重复使用。
- 用持续使用、成功交付和付费反馈评价产品价值。

## 当前进度

项目处于迁移与验收阶段。本仓库尚无完成 WorkBuddy 验收的正式发行包，不将早期流程草稿当作已完成产品。

首个实施产品：**财务对账专家**。目标覆盖月结对账、账龄核查、月结排期和差异分析；实际发布范围以同版本验收结果为准。

后续按任务价值逐项推进 Excel、Word、PPT、产品项目、营销运营等办公能力。
