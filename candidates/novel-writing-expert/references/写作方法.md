# 从想法到连续章节

## 定故事，不设问卷门槛

先提炼一句故事承诺：谁为了什么，在什么压力下必须做出选择。把缺失信息分成两层：会改变故事的题材、主角目标和核心阻碍优先；视角、语气、人物数量、结局取向和连载节奏可以先给建议。作者已经说明的内容不再询问。提供候选书名时，让标题与真实故事冲突相关，不编造榜单或签约概率。

确定长篇前先做一个能判断风格的场景或首章。如果作者明确要整部作品，先简要说明采用的方案后直接推进；用户随时可以改变方向。设定章数与篇幅是写作计划，不是每次都必须达到的硬编码数值。

## 搭建可执行大纲

总纲写清开端的失衡、主角主动采取的策略、策略造成的代价、关键选择和结局需要解决的问题。章节计划至少保存章号、标题和本章目标；中文阅读版补充视角人物、承接事件、行动与阻碍、局势变化、应埋或应收的线索。用具体事件表述，避免十几章都只是“矛盾升级”。

人物档案关注：当下目标、害怕失去的东西、可用资源、判断盲点、关系中的利益，以及遇到代价时怎样选择。把初始设定与随剧情发生的变化分开记录。反派和配角也应有自己的目标，不只承担解释设定的作用。

世界规则优先记录会影响行动结果的约束，例如代价、权限、交通时间、技术能力、时代习惯。拿不准的真实史实标记待查；历史架空与真实考据不要混为一谈。无需外部服务也能写架空作品，不假装已联网查证。

## 写出一个有变化的场景

围绕“进入时想做什么—遇到什么阻力—采取什么行动—结果如何改变下一步”推进。把重要选择展开为行动、对话和感受，将过场压缩。不同角色的信息、身份和关系决定说话方式；重要对话应改变关系或行动，不只是互相复述设定。

题材重点可调整：

| 类型 | 优先检查 |
|---|---|
| 悬疑 | 线索何时出现、谁有机会知道、推理依靠什么证据，揭晓是否有先前依据 |
| 言情 | 情感变化是否有事件支撑，误会和和解是否符合人物掌握的信息 |
| 玄幻与成长 | 获得能力的条件和代价是否一致，胜负是否靠新增规则硬解 |
| 都市与现实 | 职业处境、关系利益与生活细节是否具体，人物决定是否有后果 |
| 历史与科幻 | 时代或技术规则能否支撑行动，未知事实是否与虚构设定分开 |
| 文学与短篇 | 意象、语气和留白是否服务主题，不强加升级套路或章末悬崖 |

结尾可以是新问题、决定的代价、关系变化或情绪余波；不要求每章都用突发惊吓。开篇尽早让读者看到值得在意的人与问题，不机械规定固定字数内必须高潮。

## 保持语言与作者一致

从作者提供的样稿或已认可章节提炼具体偏好：句子节奏、对话比例、视角距离、幽默方式、描写密度与禁用套话。用这些维度保持一致，不只写“高级、细腻、有网感”。精修时减少无信息量形容词、重复解释、整齐排比和概念式情绪描述，但保留作者有意使用的重复和个人表达。

不承诺通过任何“AI检测”，也不把修改目标变成规避检测。目标是可读、贴合人物和具有具体细节。

## 断点之后继续

恢复时确认计划章号、当前正文版本、最后已发生事件、未解决问题和用户最新要求。正文只写了一半但未入库时，将该稿与当前版本比较，再决定继续还是重新修订。若新要求改变原大纲，先改受影响的后续计划并说明影响，不重写全部已完成章节。
