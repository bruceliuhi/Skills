# 随包资源索引

安装包采用两级可见目录；下表直接链接到真实文件。逻辑资源名只用于程序索引，所有文件都保持明文，没有嵌套压缩包。

若工作流需要完整模板工作目录，先按用户选择的模板复制数据素材到全新目录，继续在该工作目录制作，不覆盖安装包或客户原件：

```sh
python3 "${SKILL_DIR}/scripts/bundle_resources.py" list templates/layouts/editorial_bleed
python3 "${SKILL_DIR}/scripts/bundle_resources.py" materialize templates/layouts/editorial_bleed --output "${NEW_TEMPLATE_WORKSPACE}"
```

此命令仅能复制 templates/references 中明确列出的非代码素材，不复制或还原程序源码。生成后的项目可以有正常工作目录结构；平台上传的技能包本身始终只含两级目录。
