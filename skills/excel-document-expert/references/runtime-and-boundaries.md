# 环境检测与选路

客户端、本机Python、付费云端是不同执行环境；导入库成功、实际生成文件、市场发布也是不同状态。

先检查当前会话真实提供的表格/Office工具与说明；本地脚本可运行时执行 `python3 scripts/runtime_check.py`。它只检查当前解释器、PATH和常见系统Python，不读取业务资料、不安装依赖。

优先级：
1. 普通及既有工作簿优先：已提供且实际可用的原生表格/Office能力，按 @references/workbuddy-native.md 发现读取、编辑、计算、保存入口；无需用户另开第三方账号或安装本地库。复杂对象仍需单独验证。
2. 普通xlsx新建与读改：能导入openpyxl的解释器。批量数据可用已有pandas，新建图表可用已有xlsxwriter。
3. 公式重算：已验证能保存文件的原生计算工具；或recalc.py配合已有soffice。
4. 缺少必要能力：说明缺口，不把提示词、CSV或未计算的公式当成完整成果。

不使用另一台机器的缓存路径，不全盘找库，不自动安装软件，不绕过环境限制。核心不要求额外账号或API密钥；环境依赖不等于本包已打包依赖或保证所有用户预装。

| 工具 | 适合 | 不能据此宣称 |
|---|---|---|
| openpyxl | 普通xlsx读改、样式、公式、图表 | 自动计算公式、任意复杂对象完全保真 |
| pandas | 清洗、合并、分组、汇总 | 保留复杂工作簿全部样式/对象 |
| xlsxwriter | 新建格式/校验/公式/图表 | 读取并局部修改已有文件、计算公式 |
| markitdown | 快速文字预览 | 精确坐标和局部修改依据 |
| LibreOffice | 副本计算与转换 | 所有新函数、数组、宏、数据模型兼容 |
| 原生工具 | 依实际说明编辑/计算/导出 | 未调用即成功、未保存即更新 |

附带scripts/validate.py对xlsx明确不做XSD校验，退出码0不能作为Excel通过证据。核心recalc.py与runtime_check.py支持Python3.9+；附带通用Office校验代码要求3.10+，不属于本技能Excel验收入口。

## 当前依赖方案

默认交付路径依赖 WorkBuddy 本次会话提供的原生编辑/计算/保存能力，库探测只用于备选路径。此包未捆绑 Python 第三方库或 LibreOffice；已有库可用，缺少时不自动安装。普通工作簿原生路径已做代表性客户端实跑，但付费云端需分别验收。若当前会话既无可保存的原生工具，也无已验证本地引擎，应明确环境阻断，不能声称“零环境依赖”。

本地 LibreOffice 转换曾发现字体替换；recalc.py 已加入字体变化阻断。错误数为零只证明公式错误扫描结果，不能替代样式与业务验收。
