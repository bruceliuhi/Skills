# 中文页面编排与可编辑SVG

## 先决定表达

先把选中材料分成：结论、证据、行动。每页一个主标题，对应一个要让受众记住的观点。没有给出结论时用中性主题，不能改写为已经验证的成效。首次制作可先完成用户要求的完整内容；材料不足的数字标为待补，不能编造统计。

统一画布建议1280×720（16:9）。留白约64–80像素；标题约40–48，正文约24–30，来源/脚注不小于18。每页保留易读行距；长段落拆为要点或多页，不能仅缩小字体塞入。中文字体建议Noto Sans CJK SC，服务端已配中文字体。

## SVG约束

- 根为标准SVG命名空间，`viewBox="0 0 1280 720"`。宽高100–4096、面积不超过900万；不超过800KB/页。
- 自由设计使用根 `data-pptx-page-role="cover|toc|section|content|ending"`。普通文字、线条、矩形、路径保持矢量可编辑；页面图块与标题可用有稳定id的group分组，并写 `data-pptx-bounds="x y width height"`。
- 使用明确位置与属性，不使用HTML、foreignObject、JavaScript、事件、CSS style标签、外部字体或外部资源URL；不使用转义资源路径或xml:base。`fill="url(#local-gradient)"`只引用本页定义。
- 图片须为已获使用权的PNG/JPEG/WebP并嵌入data URI；不从服务端任意下载外链。优先适当尺寸压缩，不能将整页截图当成可编辑PPT。
- 讲稿写在notes同名Markdown文件中，包含自然口语转折、数字解释和结尾行动；内容来自输入，单页不超过2万字符。
- 多轮编辑只调整指定页工作副本，不改输入原件或未涉及页面。

## 视觉检查

依次看标题可读、正文不溢出、数字单位与日期一致、图表无失真、表格无截断、来源准确。预览图不足以验证原生可编辑性，必须同时检查PPTX原生图表/表格与报告；报告也不能替代逐页视觉查看。

## 不完整输入

只有主题：根据用户目标先提供内容结构与待补数字，询问最关键缺失材料，不能生成假客户结果。只有图片参考：可以重建版式，标明无法读取的文字，不能宣称逐像素复原。只有链接且正文无法读取：让用户提供正文或文件，不根据标题编造。
