# PPT制作与美化专家

把资料变成能继续修改的演示文件，修改已有 PPT 时保留原稿与未改页面。

## 可以交付什么

- 根据明确的资料、结构与页数生成可编辑 PPTX。
- 在支持范围内创建原生图表、嵌入数据工作簿、表格和逐页演讲备注。
- 导入已有 PPTX，局部修改后另存；核对未修改页面、数据、资源与讲稿。
- 交付中文执行结果与实际文件，说明原件保护和未完成检查。

## 开始使用

运行 `python3 scripts/run_workbuddy.py doctor` 只读核对当前环境。启动器先寻找平台已有且具备核心库的解释器；依赖不足时可在项目内全新虚拟环境自动准备固定核心组件。只从官方 PyPI 获取，不全局安装、不改安全保护、不使用开发工具私有缓存，也不需要第三方账号。

核心需要 Python 3.9+、python-pptx、XlsxWriter、Pillow、lxml。详细操作见 [中文交付流程](references/workbuddy-delivery.md)。首次完整性检查失败时重新安装完整包，不跳过检查。

## 交付边界

普通生成与三页往返修改已有实际文件验收。自动浏览器预览在当前验证环境未完成；没有真实预览时明确告知，不能说已经逐页视觉检查。付费云端环境尚需单独核验，不把本地运行成功当成云端可用证明。

本包提供中性布局、风格、图表和表格参考，不附大规模图标、音效、品牌或图片素材库。可使用用户提供的素材。布尔图形、文字轮廓、互动预览、音频/视频与外部图像服务需要相应环境；不属于无需额外服务的默认承诺。

不承诺任意 PPT 无损转换或不同办公软件像素一致。缺材料、依赖或权限时明确停止点，保留已有文件，不把大纲、截图或空文件冒充可编辑交付。

## 平层安装包与模板使用

本包所有脚本和资源直接可见，最多两级目录。需要读取或复制内置模板时先查 [平层资源索引](references/平层资源索引.md)。工作流中的客户项目目录保持正常结构；安装包内的旧逻辑路径由明确索引映射，不应手动拼接成不存在的深层安装路径。需要模板工作目录时使用 `scripts/bundle_resources.py materialize` 复制选定素材到新目录，再继续原制作流程。
